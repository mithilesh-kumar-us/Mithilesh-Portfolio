# Project Images

Place your project screenshots and images in this directory.

## Recommended Naming Convention

- `ecommerce.png` - E-commerce project screenshot
- `taskapp.png` - Task management app screenshot
- `ai-content.png` - AI content generator screenshot
- etc.

## Recommended Dimensions

- Aspect ratio: 16:9
- Minimum size: 800x450px
- Recommended size: 1200x675px

## Supported Formats

- PNG (recommended for screenshots)
- JPG/JPEG
- WebP (best for performance)
